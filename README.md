# VODOS אונליין

הפיד של [VODOS](https://xnet2.github.io/VOD/) כאפליקציה לאנדרואיד, שמנגנת את הסרטונים ישר מהאינטרנט.
אותו מסך ואותם כפתורים כמו ב-[VODOS לנגן](https://github.com/Xnet2/vodos-offline), אבל בלי מחשב ובלי סרטונים שנשמרים במכשיר.

## הורדה

**[VODOS-online.apk](https://github.com/Xnet2/vodos-online/releases/latest/download/VODOS-online.apk)** (הגרסה האחרונה תמיד)

עמוד האפליקציה: https://xnet2.github.io/projects/vodos-online.html

## התקנה

1. מורידים את `VODOS-online.apk`, ישר במכשיר או במחשב ומעבירים אליו.
2. פותחים את הקובץ ומתקינים. אם המכשיר מבקש, מאשרים התקנה ממקור לא ידוע.
3. פותחים את VODOS אונליין. הסרטונים נטענים מהאינטרנט.

## מה יש בה

- כל הסרטונים מכל הערוצים, ישר מהאתר, באותו סינון ובאותו סדר
- גלילה אנכית, "עדכני" ו"לא נצפו"
- אהבתי, חיפוש, חלונית ערוץ והיסטוריית צפייה
- הורדת סרטון לגלריה (Movies/VODOS) ושיתוף

## דרישות

אנדרואיד 4.4 ומעלה, וחיבור לאינטרנט.
